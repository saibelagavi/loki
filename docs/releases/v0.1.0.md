The first public release of **LOKI (Local Only Key Inventory)**: an encrypted, offline home for every
`.env` file you own, built for the day you push to production.

## What it does

- **Compare matrix**: keys as rows, your targets (branch + stage) as columns. Every cell says same,
  differs, missing, empty or extra, computed from encrypted fingerprints without decrypting anything.
- **Push-day check**: staging → production findings: keys missing in production, `sk_test_` keys,
  `localhost` URLs, placeholder values, secrets shared across stages, `DEBUG=true`. Export a
  Markdown checklist (keys only) or just the missing keys.
- **Push-day overview**: release readiness for every project, `.env` files that changed on disk, and
  secrets due for rotation.
- **Diff checker**: compare real values between any two sources, with character-level highlights.
- **Versions and history**: every import is an immutable version; diff, restore, re-import.
- **Secure share**: bundle projects, `.env` files or some keys into one encrypted `.lokishare` file
  that opens only with a one-time pass key LOKI generates.
- **Passwords**: logins that are not in a `.env`, with weak and reused flags.
- **Search across projects** (Ctrl+K), key notes, encrypted `.loki` backups, an audit log, auto-lock,
  dark and light themes, and full keyboard use.

LOKI has no network code at all. Values are encrypted with XChaCha20-Poly1305 under keys derived
from your master password with Argon2id; the password is never stored. See
[SECURITY.md](https://github.com/saibelagavi/loki/blob/main/SECURITY.md).

## Download

| File | For |
|---|---|
| `LOKI_0.1.0_x64-setup.exe` | Most people. Installs for all users into `C:\Program Files\LOKI`. |
| `LOKI_0.1.0_x64_en-US.msi` | IT-managed machines and silent installs (`msiexec /i … /quiet`). |
| `SHA256SUMS.txt` | Checksums to verify the download. |

Both installers include the WebView2 runtime, so offline machines work. Windows 10 and 11, x64.

**Verify the download** (PowerShell), then compare with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LOKI_0.1.0_x64-setup.exe -Algorithm SHA256
```

The installers are not code-signed yet, so Windows SmartScreen may warn. Choose **More info → Run
anyway** only for files downloaded from this Releases page. A Microsoft Store version, signed by
Microsoft, is on the way.

## Your data

The vault lives in `%LOCALAPPDATA%\LOKI` (Settings → Your data shows the folder). Uninstalling or
reinstalling LOKI never deletes it. To remove everything, uninstall LOKI and then delete that folder.
**Remember your master password: LOKI cannot recover it.**
