A packaging release. **The app itself is the same as [0.1.0](https://github.com/saibelagavi/loki/releases/tag/v0.1.0)**: no new features and no fixes, so there is no need to update if you already run 0.1.0.

## What changed

- **Microsoft Store package.** The Store version now excludes only one folder, `%LOCALAPPDATA%\LOKI` (your vault), from Windows' app-storage redirection, as Microsoft's certification asked. Because that per-folder setting exists only on Windows 11, the Store version requires Windows 11. On Windows 10, use the installers below.
- **Checksums** in `SHA256SUMS.txt` now use Unix line endings, so `sha256sum -c SHA256SUMS.txt` works on Linux and macOS as well as `Get-FileHash` on Windows.

## Download

| File | For |
|---|---|
| `LOKI_0.1.1_x64-setup.exe` | Most people. Installs for all users into `C:\Program Files\LOKI`. |
| `LOKI_0.1.1_x64_en-US.msi` | IT-managed machines and silent installs (`msiexec /i … /quiet`). |
| `SHA256SUMS.txt` | Checksums to verify the download. |

Both installers include the WebView2 runtime, so offline machines work. Windows 10 and 11, x64.

**Verify the download** (PowerShell), then compare with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LOKI_0.1.1_x64-setup.exe -Algorithm SHA256
```

The installers are not code-signed yet, so Windows SmartScreen may warn. Choose **More info → Run anyway** only for files downloaded from this Releases page.

## Your data

The vault lives in `%LOCALAPPDATA%\LOKI` (Settings → Your data shows the folder). Installing this version over 0.1.0, or uninstalling and reinstalling, keeps it. **Remember your master password: LOKI cannot recover it.**
