A small release about your data: where it lives, and how to remove it for good.

## What changed

- **Delete all LOKI data.** Settings → Your data has a new button that deletes the vault and the safety copies made before upgrades, then closes LOKI. It asks for your master password and for `DELETE` to be typed, and it only removes files LOKI created. Export an encrypted backup first if you may need anything again.
- **The create-vault screen says where your vault is saved**, that uninstalling keeps it, and how to remove it.
- **Microsoft Store version:** the window's browser cache now lives in the app's own package storage, which Windows removes on uninstall, so `%LOCALAPPDATA%\LOKI` holds only your vault and its safety copies. The installer version is unchanged.

## Download

| File | For |
|---|---|
| `LOKI_0.1.2_x64-setup.exe` | Most people. Installs for all users into `C:\Program Files\LOKI`. |
| `LOKI_0.1.2_x64_en-US.msi` | IT-managed machines and silent installs (`msiexec /i … /quiet`). |
| `SHA256SUMS.txt` | Checksums to verify the download. |

Both installers include the WebView2 runtime, so offline machines work. Windows 10 and 11, x64.

**Verify the download** (PowerShell), then compare with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LOKI_0.1.2_x64-setup.exe -Algorithm SHA256
```

The installers are not code-signed yet, so Windows SmartScreen may warn. Choose **More info → Run anyway** only for files downloaded from this Releases page.

## Your data

The vault lives in `%LOCALAPPDATA%\LOKI` (Settings → Your data shows the folder). Installing this version over an earlier one, or uninstalling and reinstalling, keeps it. **Remember your master password: LOKI cannot recover it.**
